KazanBox — Privacy Policy

Last updated: 2026-09-15

What KazanBox is

KazanBox is a single-user desktop application for Windows. Its owner installs and runs it on their

own computer to prepare and publish their own social media content (short product-discovery videos

with the advertising disclosure required by Turkish advertising rules and by the merchants' affiliate

terms). There is no KazanBox server, no hosted service and no user account system: the application

runs only on the owner's computer.

What data the application handles

• **The owner's own connected accounts:** account identifier and display name returned by the

platform (for example TikTok open_id and display name, YouTube channel id and title), used only

to confirm that the correct account is connected.

• **OAuth tokens** issued by the platforms for the owner's own accounts.

• **Content data:** the videos rendered on the owner's computer, their titles, descriptions,

disclosures, hashtags and publish times.

• **Affiliate data:** product, offer and tracking-link records taken from the affiliate providers'

own pages and official reports, and the commission rows from those official reports.

• **Platform metrics of the owner's own posts** (for example view and like counters reported by the

platform's own API or screens).

The application does not collect or process other people's personal data. It does not read other

users' accounts, messages, followers or private data.

Where data is stored

All data stays on the owner's computer: an SQLite database and local files under the installation

folder. OAuth tokens and API keys are encrypted with the Windows Data Protection API (DPAPI) for the

current user and are never written to plain-text files, logs or source code.

What data is sent where

Data is sent only to the official APIs and websites of the services the owner connects: the social

platform the content is published to (for example TikTok, YouTube), and the affiliate providers whose

official data and reports the owner uses. No data is sent to KazanBox (there is no KazanBox server),

to analytics services or to advertising networks.

YouTube API Services

KazanBox uses the official YouTube Data API only for the owner's own KazanBox channel. It requests

youtube.upload to upload videos approved by the owner and youtube.readonly to verify the selected

channel, publication status, and official metrics. KazanBox does not access another user's channel or

private YouTube data. Use of information received from YouTube APIs follows the YouTube API Services

Terms of Service and the Google Privacy Policy: https://policies.google.com/privacy

What data is never used

Platform data is not sold, rented, shared with third parties, used for advertising targeting, or used

to train machine-learning models. The application does not scrape platforms, does not create

synthetic views, clicks, conversions or revenue, and does not send automated requests to affiliate

tracking links.

Retention and deletion

Data is kept as long as the owner keeps it on their computer. The owner can delete everything by

removing the application's data folder, and can revoke the application's access at any time from the

platform's own settings (for example TikTok Settings > Security and permissions > Manage app

permissions, or Google Account > Third-party access). Revoking access stops all API use immediately.

The owner may also request deletion or ask a privacy question by emailing the contact address below.

Children

The application is used only by its adult owner and is not directed to children.

Changes

If this policy changes, the new version is published at the same address with an updated date.
